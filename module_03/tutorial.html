Module 03 — Visualisation: Seeing the Evidence

Beginner A chart is a compressed story. Learn to tell it well and you'll spot patterns that would take hours to find in raw numbers.

00 — The Matplotlib Mental Model

Matplotlib uses a two-level object hierarchy: a Figure (the canvas) containing one or more Axes (the plot area). Always work with the ax object — it gives you full control.

import matplotlib
matplotlib.use("Agg")          # Windows: render to file, not screen
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 5))   # fig = canvas, ax = plot area
ax.plot([1, 2, 3], [4, 1, 3])
plt.savefig("plot.png", dpi=120)
plt.close()                              # always close — frees memory
Windows rule: Call matplotlib.use("Agg") BEFORE importing pyplot. Never call plt.show() — always plt.savefig(). The Agg backend renders to file without needing a display.

01 — Line Plot

Best for: trends over time, continuous data, rolling averages.

days = np.arange(1, 31)
cases = 10 + 5 * np.sin(days / 3) + rng.normal(0, 1, 30)

fig, ax = plt.subplots(figsize=(10, 4), facecolor="#0d1117")
ax.set_facecolor("#161b22")

ax.plot(days, cases, color="#58a6ff", linewidth=1.5, alpha=0.5, label="Daily")
# 7-day rolling mean — smooths noise to reveal trend
rolling = pd.Series(cases).rolling(7, center=True).mean()
ax.plot(days, rolling, color="#f0883e", linewidth=2.5, label="7-day avg")

ax.set_xlabel("Day",   color="#e6edf3")
ax.set_ylabel("Cases", color="#e6edf3")
ax.set_title("Case Trend", color="#e6edf3")
ax.legend(facecolor="#0d1117", labelcolor="#e6edf3")
ax.tick_params(colors="#8b949e")
ax.spines[:].set_color("#30363d")

03 — Bar Chart

Best for: comparing discrete categories. Use horizontal bars when category labels are long.

# Vertical bars
ax.bar(categories, values, color="#58a6ff", edgecolor="#0d1117")

# Horizontal bars (better for long labels)
ax.barh(categories, values, color="#3fb950")

# Grouped bars (multiple series)
x = np.arange(len(categories))
width = 0.35
ax.bar(x - width/2, values_a, width, label="Series A", color="#58a6ff")
ax.bar(x + width/2, values_b, width, label="Series B", color="#f85149")
ax.set_xticks(x)
ax.set_xticklabels(categories)

04 — Histogram

Best for: understanding the distribution of a single variable.

ax.hist(data, bins=30, color="#bc8cff", edgecolor="#0d1117", alpha=0.85)

# Add mean and median lines to show skewness
ax.axvline(data.mean(),   color="#f85149", linestyle="--", label="Mean")
ax.axvline(np.median(data), color="#3fb950", linestyle="--", label="Median")
Tip: When mean > median, the distribution is right-skewed (long tail on the right). This is common for income, case durations, and many ML features.

05 — Box Plot

Best for: comparing distributions across groups, visualising quartiles and outliers.

# One box per group
groups = [data[data["district"]==d]["cases"].values for d in districts]

# The box spans Q1–Q3 (interquartile range)

06 — Multiple Subplots

# Grid of plots
fig, axes = plt.subplots(2, 3, figsize=(14, 8))
axes[0, 0].plot(...)    # row 0, col 0
axes[1, 2].scatter(...) # row 1, col 2

# Or iterate over all axes
for ax in axes.flat:
    ax.set_facecolor("#161b22")

# After all plots:
plt.tight_layout()            # avoid overlapping labels
plt.savefig("grid.png", dpi=120, facecolor=fig.get_facecolor())

10 — Q&A Brain Check

Q: Why do we call plt.close() after saving?
A: Each figure holds references to its data and artists in memory. Without closing, a loop that creates 100 plots will accumulate 100 figures in RAM. plt.close() frees that memory. Use plt.close("all") to close every open figure at once.
Q: When should you use a log scale?
A: When your data spans several orders of magnitude (e.g. prices from $1 to $1,000,000, or population counts). Use ax.set_yscale("log"). Log scales make exponential growth look linear and make small values visible when large ones dominate.
Q: What's the difference between fig.savefig() and plt.savefig()?
A: plt.savefig() saves the current active figure. fig.savefig() explicitly saves the figure object fig. When working with multiple figures, always use fig.savefig() to be explicit about which one you're saving.
Q: What does alpha control in a plot?
A: Transparency. alpha=1.0 is fully opaque; alpha=0.0 is invisible. Using alpha=0.4 on overlapping scatter points lets you see density — where many points stack, the colour darkens.
