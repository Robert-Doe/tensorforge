Key idea: Convolutional networks process a fixed spatial grid. Recurrent networks process one element at a time, maintaining a hidden state that carries memory of all previous elements. LSTMs extend vanilla RNNs with gating mechanisms to control what to remember and what to forget over long sequences.

Module 27 — RNNs & LSTMs

Ada learns to read a case file one word at a time — and remember what mattered

01 · The Big Analogy

Ada receives a case report one word at a time, transmitted over a slow teletype machine. She can't see the whole report at once — just the current word. But she has a notepad (the hidden state). After reading each word, she updates her notepad: "new clue received — suspect previously mentioned, update suspicion level." By the time the last word arrives, her notepad contains a summary of the entire report.

That's a Recurrent Neural Network. The notepad is the hidden state vector h_t. Each word is an input x_t. The update rule is: h_t = tanh(W_hh × h_{t-1} + W_xh × x_t + b). After the last word, h_T is handed to the classifier.

The problem: after very long reports, the tanh squashing function means early words gradually get "washed out" of the notepad. Ada reads 200 words and forgets the first clue. This is the vanishing gradient problem. LSTMs give her a second, more permanent notepad (the cell state) with explicit controls for what to keep and what to erase.

03 · LSTM Gates — Four Controls

🚪 Forget Gate

f_t = σ(W_f·[h_{t-1}, x_t] + b_f)
Values ∈ (0,1). 0 = erase cell memory. 1 = keep it. Learned to forget irrelevant history.

✏️ Input Gate

i_t = σ(W_i·[h_{t-1}, x_t] + b_i)
Controls how much of the new candidate value to write into the cell state.

📝 Cell Candidate

g_t = tanh(W_g·[h_{t-1}, x_t] + b_g)
The proposed new content to potentially write. Range (-1, 1).

📤 Output Gate

o_t = σ(W_o·[h_{t-1}, x_t] + b_o)
Controls what fraction of the cell state to expose as h_t.
# Cell state and hidden state updates:
c_t = f_t * c_{t-1} + i_t * g_t   # long-term memory: forget old + write new
h_t = o_t * tanh(c_t)             # short-term output: controlled peek at cell
Why does LSTM solve vanishing gradients? The cell state update is additive: c_t = f_t * c_{t-1} + i_t * g_t. When the forget gate is near 1, the gradient flows back through time without being squashed by tanh (unlike vanilla RNN). This "gradient highway" can carry useful gradient signal hundreds of timesteps back.

04 · The Model Code

class SentimentLSTM(nn.Module):
    def __init__(self, vocab_size, embed_dim=64, hidden_dim=128, num_layers=2, dropout_p=0.3):
        super().__init__()
        # Embedding: integer token id → dense float vector
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)

        # nn.LSTM handles all four gates internally
        self.lstm = nn.LSTM(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True,               # input shape: (B, seq_len, embed_dim)
            dropout=dropout_p,              # applied between stacked LSTM layers
        )
        self.dropout = nn.Dropout(p=dropout_p)
        self.fc      = nn.Linear(hidden_dim, 1)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):                   # x: (B, seq_len) integer token ids
        embedded   = self.embedding(x)     # (B, seq_len, embed_dim)
        _, (h_n, _) = self.lstm(embedded)  # h_n: (num_layers, B, hidden_dim)
        last_hidden = h_n[-1]              # top layer's final hidden state: (B, hidden_dim)
        return self.sigmoid(self.fc(self.dropout(last_hidden)))  # (B, 1) probability

05 · Gradient Clipping

# In the training loop, BEFORE optimizer.step():
nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# What this does:
# 1. Compute the global L2 norm of all gradients stacked into one vector
# 2. If that norm > max_norm, scale all gradients down proportionally
# 3. Gradients ≤ max_norm are left unchanged
Why is clipping needed for RNNs? Backprop through time multiplies gradients at each timestep. Even with LSTM gates dampening the worst cases, the product of 20 weight matrices can occasionally produce very large gradient norms — enough to take a wild optimization step and ruin training. Clipping caps this without killing gradients that are within bounds.

07 · Brain Exercise

The LSTM uses the last hidden state h_n[-1] as the review representation. For the sentence "this film was not great", the word "not" appears at position 4 of 6, and "great" at position 5.

What would happen if you reversed the word order before feeding it to the LSTM? Would "not great this was film" get classified the same way? Why or why not?

Answer: Likely differently, because the final hidden state represents the sequence ending — "film" would now be the last word processed, which has weaker sentiment signal than "not great." This is why many NLP pipelines use bidirectional LSTMs (nn.LSTM(bidirectional=True)): they run the sequence forwards AND backwards and concatenate the final hidden states, capturing context from both ends. The final representation then sees "not great" at the sequence end regardless of direction, giving better accuracy on negations and trailing modifiers.

08 · Q&A

Q: Why do we need an Embedding layer? Can't we just one-hot encode words?
One-hot vectors are sparse (vocab_size elements, one non-zero). With vocab_size=10,000, one-hot vectors are 10,000-dimensional — expensive to multiply by W_xh. Embeddings are dense low-dimensional representations (64 dimensions) that are learned alongside the model. Semantically similar words end up close in embedding space — "brilliant" and "excellent" cluster together because they appear in similar review contexts. One-hot encoding has no notion of word similarity.
Q: What is padding_idx=0 in the Embedding layer?
Reviews are padded to MAX_SEQ_LEN with zeros (the PAD token). padding_idx=0 tells the Embedding layer to always return a zero vector for index 0, and to exclude that index from gradient updates. Without this, the PAD token would have a learnable embedding that drifts during training — but it carries no linguistic meaning, so polluting the embedding space with it is wasteful.
Q: What's the difference between h_n and the output of nn.LSTM?
nn.LSTM returns two things: output of shape (B, seq_len, hidden_dim) — the hidden state at every timestep for the top layer only — and (h_n, c_n) where h_n is shape (num_layers, B, hidden_dim) — the final hidden state of every layer. We use h_n[-1] (the top layer's final h) for classification. We'd use output if we wanted to do something at every timestep — like sequence labelling (tagging each word with its part of speech).
