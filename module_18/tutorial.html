You cannot draw a single straight line that separates the 1s from the 0s. A single neuron (logistic regression) can never achieve 100% accuracy on XOR. But a network with one hidden layer can — it learns a non-linear boundary.

02 · The Layer Abstraction

Instead of writing one giant forward/backward function, each layer is responsible for its own computation:

class DenseLayer:
    def forward(self, X):
        self._cache = X            # save for backward
        return X @ self.W + self.b

    def backward(self, dOut):
        self.dW = self._cache.T @ dOut / n   # weight gradient
        self.db = dOut.mean(axis=0)
        return dOut @ self.W.T    # pass gradient further back

class ReLULayer:
    def forward(self, X):
        self._cache = X
        return np.maximum(0, X)

    def backward(self, dOut):
        return dOut * (self._cache > 0)   # zero where ReLU was off

The MLP just runs through the list of layers — forward in order, backward in reverse:

# Forward
out = X
for layer in self.layers:
    out = layer.forward(out)

# Backward
grad = loss_gradient
for layer in reversed(self.layers):
    grad = layer.backward(grad)

05 · Brain Exercise

The single neuron gets 75% on XOR. Why 75% and not 50%? Draw the four XOR points on a 2D grid and draw the best possible straight line through them.

Then: why can a 2-layer MLP learn XOR when a single neuron can't?

Answer 1: Three of the four XOR points can be correctly separated by a horizontal or vertical line (e.g., "output=1 when B=1" correctly handles [0,1] and [1,0] but not [1,1]). That's 3/4 = 75%.

Answer 2: The hidden layer transforms the input into a new feature space where the classes are linearly separable. Concretely: one hidden neuron learns "are A OR B present?" and another learns "are both A AND B present?" The output neuron then learns OR - AND, which equals XOR. Each step is linear; the combination through the non-linear activation is not.

06 · Q&A

Q: How does this layer abstraction relate to PyTorch?
PyTorch's nn.Module is this exact pattern with automatic differentiation added. nn.Linear is our DenseLayer; nn.ReLU is our ReLULayer. The difference is that PyTorch computes backward() automatically using autograd — you never write it by hand. Module 22 shows the PyTorch version of this exact MLP.
Q: What is "universal approximation theorem"?
It states that a neural network with a single hidden layer of sufficient width can approximate any continuous function to arbitrary precision (given enough neurons and data). This is why we know MLPs are powerful in principle. In practice, deeper-but-narrower networks often generalise better than one extremely wide hidden layer.
Q: Why does full-batch gradient descent work here but might fail on larger datasets?
Full-batch GD computes the gradient over all 96 samples simultaneously — fine for small data. On large datasets (millions of samples), computing the full gradient each step is too slow. Mini-batch SGD (Module 20) uses random subsets of data per step, making each update faster at the cost of noisier gradients.
