Module 04 — Linear Regression: Predicting the Next Crime Wave

Beginner Our first predictive model. Given what we know about today, predict a number for tomorrow.

00 — The Core Idea

Linear regression finds the best-fit line (or hyperplane) through data points. "Best-fit" means the line that minimises the total squared distance between predictions and actual values.

ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ
  • β₀ — intercept (predicted value when all features = 0)
  • β₁...βₚ — coefficients (how much ŷ changes per unit of each feature)
  • ŷ — predicted value (a number, not a probability)

The model learns β by minimising Mean Squared Error over the training set:

MSE = (1/n) Σ (yᵢ - ŷᵢ)²

01 — The Golden Rule: Split First

Cardinal rule: Split your data into train and test sets BEFORE any fitting, scaling, or preprocessing. Doing it after leaks test information into training — your model will appear better than it really is on new data.
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.2,          # 20% held out for testing
    random_state=42,        # reproducible split
)
# Everything learned from here uses ONLY X_train, y_train
# X_test, y_test are locked away until final evaluation

02 — Fitting the Model

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)       # learn β₀, β₁, β₂, ...

print(model.intercept_)           # β₀
print(model.coef_)                # [β₁, β₂, ...]

# Make predictions
y_pred = model.predict(X_test)    # apply learned β to new X

03 — Evaluation Metrics

MetricFormulaInterpretation
MSE(1/n) Σ (y - ŷ)²Average squared error. Penalises large errors heavily.
RMSE√MSESame units as target. "On average, off by X cases."
MAE(1/n) Σ |y - ŷ|Average absolute error. Robust to outliers.
R²1 - SS_res/SS_totFraction of variance explained. 1=perfect, 0=predicts mean.
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
import numpy as np

mse  = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
mae  = mean_absolute_error(y_test, y_pred)
r2   = r2_score(y_test, y_pred)

print(f"RMSE: {rmse:.2f}   MAE: {mae:.2f}   R²: {r2:.4f}")
Always evaluate on BOTH train and test. If train R²=0.95 and test R²=0.60, the model is overfitting — memorising training data, not generalising.

04 — Residual Analysis

Residuals = actual − predicted. They should:

  • Have mean ≈ 0 (no systematic bias)
  • Be randomly scattered (no pattern vs fitted values)
  • Have roughly constant spread (no fan shape — homoscedasticity)
residuals = y_test - y_pred

# Residuals vs Predicted — look for patterns
ax.scatter(y_pred, residuals, alpha=0.5)
ax.axhline(0, color="red", linestyle="--")

# Fan shape → heteroscedasticity → try log(y)
# Curve      → non-linearity   → try polynomial features

05 — Multiple Features

FEATURES = ["temp_c", "is_weekend", "day_of_week", "prev_day_cases"]
X = df[FEATURES].values   # (n_samples, 4)
y = df["cases"].values    # (n_samples,)

# Same API regardless of number of features
model = LinearRegression().fit(X_train, y_train)

# Each coefficient = effect of that feature holding others constant
for name, coef in zip(FEATURES, model.coef_):
    print(f"  {name}: {coef:+.3f}")

06 — Assumptions of Linear Regression

  1. Linearity: the relationship between X and y is linear. If not, add polynomial features or use a non-linear model.
  2. Independence: observations are independent (no time-series autocorrelation without handling it).
  3. Homoscedasticity: residual variance is constant across all fitted values.
  4. Normality of residuals: matters for confidence intervals and hypothesis tests; less critical for prediction.
  5. No multicollinearity: features should not be highly correlated with each other (inflates coefficient variance).
Practical note: For prediction (not inference), assumptions 3–5 can be partially violated without catastrophic loss of accuracy. But assumption 1 (linearity) matters most — fix it with feature engineering.

07 — When Linear Regression Fails

Problem: curved relationship

Add polynomial features:
PolynomialFeatures(degree=2)

Problem: outliers pulling the fit

Use HuberRegressor or log-transform the target.

Problem: too many features (p ≫ n)

Use Ridge or Lasso regularisation (Module 04 advanced).

Problem: target is 0/1 or a count

Use Logistic Regression (Module 05) or Poisson regression.

09 — Q&A Brain Check

Q: What does a negative coefficient mean?
A: As that feature increases by 1 unit, the predicted target decreases by |coef| units (holding all other features constant). For example, β(is_holiday) = -3 means holidays predict 3 fewer cases per day.
Q: What does R² = 0 mean?
A: The model does no better than predicting the training mean for every sample. Your features have zero predictive power — or the relationship is non-linear and the model can't capture it.
Q: Why is RMSE more interpretable than MSE?
A: MSE is in squared units (cases²). RMSE takes the square root to return to the original unit (cases), making it directly comparable to the scale of your target variable.
Q: Does linear regression require feature scaling?
A: For prediction accuracy: no — the normal equation solution is scale-invariant. For coefficient interpretation: yes — coefficients are only comparable when features are on the same scale. For regularised regression (Ridge/Lasso): yes, always scale, or the regularisation penalises large-scale features unfairly.
