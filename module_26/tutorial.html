00 · Before You Start

Prerequisites: Modules 24–25 (CNNs in PyTorch, BatchNorm, Dropout). PyTorch and torchvision must be installed.

Downloads: ResNet-18 weights (~45 MB, once) + CIFAR-10 (~170 MB, once).

Key idea: A network trained on 1.28 million images already knows how to detect edges, textures, and shapes. You can steal those skills and apply them to your task — training only a tiny new head instead of the entire network from scratch.

Module 26 — Transfer Learning

Ada acquires a veteran detective's case files and ignores rookie mistakes

01 · The Big Analogy

Imagine Ada needs to solve cases in a new city she's never worked in. Starting completely from scratch, she'd need years to learn the local street layout, criminal patterns, and informant network. But there's a veteran detective — let's call her ResNet — who spent 20 years working cases in 1,000 different cities (ImageNet classes). ResNet's brain is packed with hard-won pattern recognition: she can spot a suspicious vehicle, recognise a wanted face in a crowd, and identify which neighbourhood a photo was taken in.

Ada doesn't need to re-learn all of that. She borrows ResNet's brain (frozen — don't change what works), glues on her own small decision module on top (the new classification head), and trains only that module on her local cases (CIFAR-10). The borrowed brain provides universal visual skills; the new head specialises them for the local task.

After just 5 epochs with a frozen backbone, Ada's new module reaches ~88% accuracy on categories it's never seen during its 20-year career — because the underlying visual skills transfer perfectly.

"Frozen" means param.requires_grad = False. Gradients flow through frozen layers during the backward pass (they must — to reach the head), but no weight update is applied. Only the trainable layers are updated by the optimizer.

03 · The Code

from torchvision import models

# Load ImageNet-pretrained ResNet-18
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

# Freeze the backbone — no updates to conv/BN/residual layers
for param in model.parameters():
    param.requires_grad = False

# Replace the output head (was 1000 ImageNet classes → now 10 CIFAR classes)
in_features = model.fc.in_features         # 512 for ResNet-18
model.fc = nn.Sequential(
    nn.Linear(in_features, 256),
    nn.BatchNorm1d(256),
    nn.ReLU(inplace=True),
    nn.Dropout(p=0.4),
    nn.Linear(256, 10),                    # 10 CIFAR-10 classes
)

# Only pass trainable params to optimizer — frozen params waste memory in Adam
optimizer = optim.Adam(
    filter(lambda p: p.requires_grad, model.parameters()),
    lr=1e-3
)
ImageNet normalisation is mandatory. ResNet's convolutional filters learned to activate on images normalised with ImageNet statistics (mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]). Feeding it raw pixels or MNIST-normalised images produces garbage features. Always match the normalisation used during pretraining.

04 · Three Strategies

StrategyWhat's trainedLRBest when
Frozen backbone New head only (~500K params) 1e-3 Small dataset (<5K images), similar domain to ImageNet
Full fine-tune All 11M params 1e-4 (10× lower) Medium dataset, task differs from ImageNet, want max accuracy
From scratch All 11M params (random init) 1e-3 Very large dataset (>1M images), very different domain (medical, satellite)

The 10× lower LR for full fine-tuning is critical. The backbone is already near a good solution; a normal learning rate would overshoot and destroy the learned representations in the first few steps.

05 · ResNet Input Size

# CIFAR-10 images are 32×32.
# ResNet's first conv layer uses a 7×7 kernel with stride=2.
# After first conv: 32 → 16. After first max-pool (stride=2): 16 → 8.
# By the final residual block, spatial dims are 1×1 — too small for the
# average-pool that follows. ResNet needs at least 224×224 input.

transform = transforms.Compose([
    transforms.Resize(224),     # upscale 32×32 → 224×224
    transforms.ToTensor(),
    transforms.Normalize((0.485, 0.456, 0.406), (0.229, 0.224, 0.225)),
])
Upsizing 32×32 → 224×224 adds no real information (the image is blurry at 224), but it satisfies ResNet's spatial requirements. In practice, you'd use a dataset of naturally large images (≥224) — CIFAR-10 is used here for speed.

07 · Brain Exercise

The "frozen backbone" experiment trains only 1.2% of the model's parameters yet reaches 88% accuracy. The "from scratch" experiment trains 100% of parameters yet only reaches 70% after 5 epochs.

Why does training fewer parameters lead to better results here? What would happen if you ran "from scratch" for 50 epochs instead of 5?

Answer: With frozen pretraining, the 98.8% of frozen parameters already encode powerful generic image features (edges, textures, object parts) built from 1.28 million labelled images. The tiny trainable head just needs to learn which of those 512 features predict each CIFAR class — a much easier optimisation problem. "From scratch" must learn all 11M parameters from 50,000 CIFAR images — heavily underdetermined. Running from-scratch for 50 epochs would likely reach 85–90%, but with much higher variance and risk of overfitting. Transfer learning is not just faster — it also requires much less data.

08 · Q&A

Q: How do I use my own folder of images instead of CIFAR-10?
Use torchvision.datasets.ImageFolder. Organise your images as:
data/train/cat/img1.jpg, data/train/dog/img2.jpg, etc.
Then: dataset = ImageFolder("data/train", transform=val_transform)
The folder names become class labels automatically. The same DataLoader, model, and training loop work unchanged.
Q: Why does full fine-tuning use a 10× lower learning rate?
The pre-trained backbone weights are already near a good local minimum of the loss landscape. A normal learning rate (1e-3) would overshoot this minimum and land somewhere worse on the first update. Using 1e-4 takes tiny steps that move the backbone only slightly — "nudging" rather than "jumping." If full fine-tuning with lr=1e-3 doesn't outperform the frozen baseline, the learning rate is the first thing to lower.
Q: What if my task is very different from ImageNet (e.g. X-ray classification)?
Transfer still works, just less dramatically. Early conv layers (edges, gradients) transfer well to any image domain. Middle layers (textures, patterns) transfer reasonably. Deep layers (faces, cars, dogs) are ImageNet-specific and may need more fine-tuning. The practical approach: start frozen, measure accuracy, then progressively unfreeze later layers if accuracy is insufficient. Models pretrained on medical image datasets (e.g. CheXNet) would transfer better to X-rays than ImageNet-pretrained ResNet.
Q: What is ResNet's "residual" connection, and why does it matter for transfer?
Each ResNet "block" computes output = F(x) + x — the block output is the learned transformation PLUS the original input (a skip connection). This prevents vanishing gradients in deep networks and means each block only needs to learn the residual (what's missing) rather than the full transformation. For transfer learning, skip connections mean that even if the new head's gradients are small, they flow back through the identity path — the backbone doesn't "forget" its pretraining catastrophically.
