Module 21 — Overfitting & Regularisation

When Ada memorises cases instead of learning patterns

01 · The Big Analogy

Ada studied 78 past cases so hard she memorised every detail — the suspect's exact age, the precise number of witnesses, the specific location. On those 78 cases she's perfect. But a new case comes in and she fails — it doesn't match any past case exactly.

She overfitted to the training data. She learned noise and quirks instead of general patterns.

Two cures:

  • L2 Regularisation: "Ada, don't obsess over any single piece of evidence. Keep all your confidence levels moderate." (Penalty for large weights.)
  • Dropout: "Ada, every day we randomly assign half your team to desk duties. Train with whichever half shows up." (Forces redundancy — no neuron can become indispensable.)

03 · L2 Regularisation (Weight Decay)

Add a penalty term to the loss that grows with the squared magnitude of the weights:

regularised_loss = loss + (lambda / 2) * sum(W^2)

# Gradient of the penalty w.r.t. W:
d/dW [lambda/2 * W^2] = lambda * W

# So in backward(), just add lambda * W to dW:
layer.dW += l2_lambda * layer.W   # weight decay step

# Effect: large weights are pulled toward zero every update
Intuition: L2 says "if two explanations fit the data equally well, prefer the simpler one (smaller weights)." It's Occam's Razor built into the loss function.

04 · Dropout

class DropoutLayer:
    def forward(self, X):
        if not self.training:
            return X   # no dropout at inference

        # Each neuron kept with probability (1-p)
        mask = (rng.random(X.shape) >= self.p).astype(float)

        # Inverted dropout: scale up to keep expected value the same
        return X * mask / (1.0 - self.p)

    def backward(self, dOut):
        if not self.training:
            return dOut
        return dOut * mask / (1.0 - self.p)   # same mask as forward
Always call model._set_training(False) before predict(). If dropout stays active at inference, your predictions are random — literally different every call. Every framework has a model.eval() / model.train() toggle for this reason.

06 · Brain Exercise

Why does dropout help with overfitting even though it seems to make training noisier and harder?

Hint: think about what a neuron learns when it can't rely on any specific other neuron always being present.

Answer: When neurons are randomly dropped, no single neuron can afford to specialise in memorising one specific training example — it might not be present for the next update. Each neuron must learn features that are useful in combination with any random subset of other neurons. This forces the network to learn multiple redundant representations of the same pattern, which generalise much better to unseen data. Dropout is essentially training an exponential ensemble of sub-networks and averaging their predictions at inference.

07 · Q&A

Q: What dropout probability should I use?
Common defaults: p=0.5 for large hidden layers, p=0.2 for smaller layers or near the output. Avoid high dropout (p>0.6) — it makes training very slow and noisy. Never apply dropout to the output layer. If validation loss doesn't improve with dropout, try reducing p or removing it entirely.
Q: What is L1 regularisation and when is it better than L2?
L1 adds lambda * sum(|W|) instead of lambda/2 * sum(W²). The key difference: L1 produces sparse weights (many exactly zero), L2 produces small-but-nonzero weights. L1 is better when you suspect many features are irrelevant and want automatic feature selection. L2 is better when all features contribute something. In neural networks, L2 (weight decay) is used almost universally.
Q: What other regularisation techniques exist beyond L2 and Dropout?
Data augmentation (artificially expand training data), early stopping (stop when val_loss plateaus), batch normalisation (M25 — stabilises training and has implicit regularisation effect), label smoothing (soften hard 0/1 targets), and DropConnect (drop individual weights rather than neurons). In practice, data augmentation + dropout + early stopping cover most real scenarios.
