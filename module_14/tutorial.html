00 · Before You Start

Prerequisites: Module 01 (NumPy), Module 13 (clustering). Matrix multiplication and the concept of a covariance matrix help but aren't strictly required.

Key concept: PCA is a coordinate rotation, not a lossy compression. You rotate the axes so the first axis points in the direction of maximum variance.

Module 14 — Principal Component Analysis

Turn 6-dimensional evidence into a 2D map you can actually see

01 · The Big Analogy

Ada has 6 evidence measurements per case. To visualise all 120 cases simultaneously she'd need a 6-dimensional chart — which doesn't fit on any screen.

She notices that two measurements often move together: cases with high evidence scores tend to have high motive scores. That redundancy means those two dimensions aren't giving her independent information.

PCA finds a new set of axes — principal components — where the first axis captures as much case-to-case variation as possible, the second captures as much of the remaining variation as possible, and so on. Then she throws away the last few axes (the ones capturing barely any variation) and plots the first two. No information is faked — only redundancy is removed.

02 · What is an Eigenvector?

When you multiply a matrix M by most vectors, the result points in a different direction. An eigenvector is special: multiplying it by M only stretches or shrinks it, never rotates it. The stretch factor is the eigenvalue.

For a covariance matrix, eigenvectors point in directions of maximum spread. The eigenvalue measures how much spread exists in that direction. The eigenvector with the largest eigenvalue = the direction in your data with the most variance = PC1.

eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
# eigenvalues:  (n_features,) — how much variance each direction captures
# eigenvectors: (n_features, n_features) — the directions themselves (columns)

03 · The Full Algorithm

# Step 1: centre
mean      = X.mean(axis=0)       # (n_features,)
X_centred = X - mean             # now each column has mean 0

# Step 2: covariance matrix
cov = (X_centred.T @ X_centred) / (n_samples - 1)   # (n_features, n_features)

# Step 3: eigendecompose (eigh for symmetric matrices)
eigenvalues, eigenvectors = np.linalg.eigh(cov)

# Step 4: sort descending — largest variance first
order        = np.argsort(eigenvalues)[::-1]
eigenvectors = eigenvectors[:, order]   # each column is one PC

# Step 5: project onto top-k components
components = eigenvectors[:, :k].T     # (k, n_features) — each row is one PC
X_projected = X_centred @ components.T # (n_samples, k)
Centre before projecting. If you forget to subtract the mean, PC1 may just point toward the centroid of the data instead of the direction of maximum variance. Always subtract the training mean — and use the same mean when transforming test data.

04 · Explained Variance and the Scree Plot

Each eigenvalue tells you how much variance the corresponding PC captures. The fraction of total variance is:

explained_ratio = eigenvalues / eigenvalues.sum()
# PC1 might capture 45%, PC2 another 22%, etc.

The scree plot shows these ratios. Look for the "elbow" — the point where adding another component gives diminishing returns. If PC1+PC2 already explain 80%+ of variance, 2D is a good projection.

06 · Brain Exercise

PC1 captures 38% of variance. Does that mean 62% of the information is lost when you use PC1 alone?

And: if you project to 2D for visualisation, does that change the clustering you'd get from k-Means?

Answer: Yes — 62% of variance is discarded when using PC1 alone. Whether that matters depends on what you're doing: for visualisation, losing variance is fine because you can still see structure. For clustering or classification, discarding variance can hurt performance. This is why we ran k-Means in the original 6D space and only used PCA for the plot — clustering in the full space preserves all information.

07 · Q&A

Q: Does PCA require feature scaling?
Yes. PCA finds directions of maximum variance, and variance is measured in the original units. A feature with values 0-365 will dominate a feature with values 0-10. Always StandardScale before PCA.
Q: What's the difference between PCA and feature selection?
Feature selection picks a subset of the original features (keep "evidence_score", drop "suspect_age"). PCA creates entirely new features (PC1, PC2) that are linear combinations of all originals. PCA features are not interpretable as original measurements — you can't say "PC1 is evidence_score."
Q: How many components should I keep?
Common rule: keep enough components to explain 90-95% of variance. Alternatively, look at the scree plot and stop at the elbow. For visualisation purposes, 2 or 3 components are the practical maximum.
Q: Can PCA be used as a preprocessing step before classification?
Yes — and it helps when you have many correlated features or want to speed up training. But fit the PCA on training data only, then transform both train and test. Using sklearn: Pipeline([("pca", PCA(n_components=k)), ("clf", LogisticRegression())]). The pipeline handles the fit/transform split correctly.
