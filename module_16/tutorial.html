Module 16 — One Neuron from Scratch

The atom of every neural network

01 · The Big Analogy

A single detective informant gives Ada one piece of intelligence. She weighs it (weight), adjusts for her prior suspicion (bias), then makes a yes/no call (activation). That's it — that's a neuron.

With six informants (six features), she does a weighted sum of their reports and applies a decision rule. The decision rule is the activation function.

02 · The Maths (familiar from M05)

z = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b   # linear combination
  = X @ w + b                             # NumPy vector form

a = sigmoid(z) = 1 / (1 + e⁻ᶻ)          # output: probability ∈ (0,1)

loss = -mean( y·log(a) + (1-y)·log(1-a) )   # binary cross-entropy

# Gradients
dL/dw = (1/n) · Xᵀ · (a - y)
dL/db = (1/n) · Σ(a - y)

# Weight update
w = w - lr · dL/dw
b = b - lr · dL/db
This is exactly Logistic Regression (M05). A neuron with sigmoid activation IS logistic regression. The new vocabulary (forward pass, activation, neuron) describes the same operations. Learning both vocabularies lets you read both ML papers and DL papers.

03 · Activation Functions

NameFormulaRangeUse
Sigmoid1 / (1 + e⁻ᶻ)(0, 1)Binary output neuron — outputs probability
ReLUmax(0, z)[0, ∞)Hidden layers — fast, doesn't saturate
Tanh(eᶻ - e⁻ᶻ) / (eᶻ + e⁻ᶻ)(-1, 1)Hidden layers — zero-centred (better than sigmoid)
Softmaxeᶻᵢ / Σeᶻⱼ(0,1) each, sum=1Multi-class output — outputs class probabilities
Why not sigmoid in hidden layers? Sigmoid "saturates" — for very large or small z, the gradient approaches zero and learning stalls (vanishing gradient). ReLU avoids this because its gradient is always 1 for positive z. More on this in M19.

05 · Brain Exercise

The test accuracy (0.750) matches our best Logistic Regression from M05. Does that surprise you? Should it?

Now imagine you had two neurons in a row. What would the second neuron receive as input? Would the output still be a linear function of x?

Answer 1: No surprise — they're the same algorithm. The neuron framing is just different vocabulary for the same gradient descent on binary cross-entropy.

Answer 2: The second neuron would receive the first neuron's activation (a number between 0 and 1). If the second neuron is also linear, the composition of two linear functions is still linear — no gain. The non-linear activation function is what breaks this chain: sigmoid(linear(sigmoid(linear(x)))) is no longer linear in x. That non-linearity is the entire reason neural networks can learn complex patterns.

06 · Q&A

Q: Why do we need an activation function at all?
Without activation functions, any stack of linear layers collapses to a single linear transformation. A 10-layer network without activations is equivalent to a single linear layer — you've built nothing more powerful than linear regression. Non-linear activations are what give neural networks their representational power.
Q: What's the difference between a neuron and a perceptron?
A perceptron (1957) uses a hard step function as activation: output is exactly 0 or 1 with no gradient at the threshold. A modern neuron uses a smooth activation (sigmoid, ReLU, tanh) whose gradient exists everywhere, enabling gradient descent training. Perceptrons couldn't learn XOR; multi-layer networks with smooth activations can learn almost anything.
Q: The weights show evidence_score and motive_strength as most important — does that match the Random Forest feature importances from M12?
Yes — both methods identified evidence_score and motive_strength as the strongest predictors. Neuron weights and tree importances measure different things (gradient sensitivity vs. impurity reduction) but often agree on the top features, which validates that these features genuinely matter in the data.

07 · What's Next

Module 17 — Backpropagation
Training a single neuron was simple — just one layer of gradients. But a network with three layers has weights at every layer. How do you compute the gradient for weights that are far from the output? The chain rule of calculus, applied systematically. That's backpropagation — the algorithm that makes deep learning possible.
