00 · Before You Start

Prerequisites: Modules 16-18 (neurons, forward pass). No PyTorch needed — this module is NumPy only.

Key idea: A convolutional layer slides a small filter (kernel) across an image and computes a dot product at each position. The result is a feature map showing where that filter's pattern was found.

Module 23 — Convolutional Layer from Scratch

Teaching a detective to look for patterns, not just numbers

01 · The Big Analogy

Ada is examining a crime scene photograph. Instead of describing every pixel, she has a set of evidence templates — a "broken window" template, a "forced door" template, a "footprint" template. She slides each template over the photo. Wherever a region of the photo matches the template closely, she marks it on a map. That map is the feature map.

A convolutional layer is Ada with a stack of templates. Each template is a learned kernel. The feature maps tell the next layer where each pattern was detected.

02 · One Output Pixel — Step by Step

A 3×3 kernel sits on a 3×3 patch of the image. Element-wise multiply, then sum. That's one output pixel.

image_patch = [[0.1, 0.8, 0.9],
               [0.1, 0.9, 0.8],
               [0.1, 0.2, 0.1]]

kernel      = [[-1, -2, -1],   # horizontal edge detector
               [ 0,  0,  0],
               [ 1,  2,  1]]

output_pixel = sum(image_patch * kernel)
             = (0.1×-1 + 0.8×-2 + 0.9×-1)   # top row
             + (0.1×0  + 0.9×0  + 0.8×0 )   # middle row (zeros)
             + (0.1×1  + 0.2×2  + 0.1×1 )   # bottom row
             = -2.4 + 0 + 0.6 = -1.8         # strong negative → bright-above-dark edge

Slide the kernel one pixel to the right, repeat. After covering the entire image: one complete feature map.

03 · The Code

def convolve2d(image, kernel, stride=1, padding=0):
    H, W   = image.shape
    kH, kW = kernel.shape

    if padding > 0:
        image = np.pad(image, padding, mode="constant")   # zero-pad edges

    H_out = (H + 2*padding - kH) // stride + 1
    W_out = (W + 2*padding - kW) // stride + 1
    feature_map = np.zeros((H_out, W_out))

    for i in range(H_out):
        for j in range(W_out):
            patch = image[i*stride : i*stride+kH,
                          j*stride : j*stride+kW]
            feature_map[i, j] = np.sum(patch * kernel)   # dot product

    return feature_map

04 · Kernels and What They Detect

Horizontal Edge

-1 -2 -1
 0  0  0
 1  2  1
Finds top/bottom edges
Top row negative, bottom positive → fires where brightness changes vertically

Vertical Edge

-1  0  1
-2  0  2
-1  0  1
Finds left/right edges
Left column negative, right positive → fires where brightness changes horizontally

Sharpen

 0 -1  0
-1  5 -1
 0 -1  0
Enhances fine details
Centre weight 5, neighbours -1 → amplifies difference between pixel and surroundings

Blur

1/9 1/9 1/9
1/9 1/9 1/9
1/9 1/9 1/9
Smooths noise
All weights equal → output is the average of the neighbourhood
CNNs don't use hand-crafted kernels. They start with random kernels and learn which patterns to detect by backpropagating the classification loss. Early layers learn edges; middle layers learn textures; deep layers learn high-level shapes like faces or wheels.

05 · Padding and Stride

ParameterEffect on output sizeUse case
padding=0Output shrinks by kH-1 and kW-1 pixelsDefault — some spatial info lost at edges
padding=1 (3×3 kernel)Output same size as input ("same" convolution)Keep spatial dimensions through many layers
stride=1Kernel moves 1 pixel at a time — dense samplingHigh-resolution feature maps
stride=2Output is half the size — spatial downsamplingReduce computation; similar to pooling

07 · Brain Exercise

The output of a single convolutional filter is a 2D feature map. A typical CNN first layer has 32 filters. What is the shape of the first layer's output for a 28×28 grayscale image with 32 filters, kernel 3×3, padding=1?

Then: what is the total number of learnable parameters in that layer (weights only, no bias)?

Output shape: (32, 28, 28) — 32 feature maps each 28×28.

Parameters: Each filter has 3×3×1 = 9 weights (1 input channel). 32 filters → 32 × 9 = 288 weights. Plus 32 biases = 320 total. Compare to a Dense layer from 784 input pixels to 32 neurons: 784 × 32 = 25,088 weights. The convolutional layer achieves the same spatial coverage with 98% fewer parameters by sharing weights — the same filter is applied at every position.

08 · Q&A

Q: Why is weight sharing so important in CNNs?
The same edge detector is useful whether an edge appears in the top-left or bottom-right of the image. Weight sharing (the same kernel applied everywhere) encodes this translational invariance. A Dense layer has no such inductive bias — it treats every pixel location independently, requiring far more parameters and data to learn translation-invariant features.
Q: What is a feature map?
The output of convolving one filter over one image. A feature map is a spatial heatmap: high values indicate positions where the filter's pattern was found, low values indicate it was absent. After 32 filters, you have 32 feature maps — each channel of the output volume represents one type of detected pattern.
Q: Why don't CNNs use the backward pass you skipped?
They do — PyTorch's nn.Conv2d computes it automatically via autograd. The backward pass for convolution is another convolution (a "transposed convolution" or "cross-correlation with a flipped kernel"). It's used to compute both dL/dKernel (to update the filter weights) and dL/dInput (to pass gradients to the previous layer). Module 24 uses autograd so you never have to implement it manually.
