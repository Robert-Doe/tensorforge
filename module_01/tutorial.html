Module 01 — NumPy: The Detective's Data Toolkit

Beginner The raw engine under every ML calculation. Before models, before plots — just fast arrays.

00 — Why NumPy?

Python lists are flexible but slow: each element is a Python object with overhead. NumPy arrays store raw C-level numbers in contiguous memory — operations run at CPU speed, not Python speed.

Python list

result = []
for x in data:
    result.append(x * 2)  # slow Python loop

NumPy array

result = data * 2  # vectorised — no loop
                   # ~100× faster on 1M elements

01 — Creating Arrays

import numpy as np

# From a Python list
a = np.array([3, 7, 2, 9, 4])      # 1-D array

# 2-D array (matrix): rows × columns
M = np.array([[10, 5, 3],
              [ 7, 8, 2],
              [ 4, 2, 9]])          # shape (3, 3)

# Constructors
np.zeros(5)                         # [0. 0. 0. 0. 0.]
np.ones((2, 3))                     # 2×3 matrix of ones
np.arange(0, 10, 2)                 # [0 2 4 6 8]
np.linspace(0, 1, 5)                # [0.  0.25  0.5  0.75  1.]
np.eye(3)                           # 3×3 identity matrix

02 — Shape, dtype, ndim

a = np.array([1, 2, 3, 4, 5, 6]).reshape(2, 3)
print(a.shape)    # (2, 3)
print(a.ndim)     # 2
print(a.dtype)    # int64 (or int32 on Windows)
print(a.size)     # 6  (total elements)
Tip: Always check .shape when debugging matrix operations. Most errors come from mismatched shapes.

03 — Indexing and Slicing

cases = np.array([3, 7, 2, 9, 4, 6, 1])

cases[0]          # 3     (first element)
cases[-1]         # 1     (last element)
cases[2:5]        # [2 9 4]
cases[::2]        # [3 2 4 1]  (every other)

# 2-D: [row, col]
M[1, :]           # second row: [7 8 2]
M[:, 2]           # third column: [3 2 9]
M[0:2, 1]         # rows 0-1, col 1: [5 8]

# Boolean indexing
cases[cases > 5]  # [7 9 6]  — only high-crime days

04 — Vectorised Operations

NumPy applies every operator element-wise — no Python for loop needed:

solved   = np.array([2, 5, 1, 7, 3, 4, 1])
unsolved = cases - solved          # element-wise subtraction
rate     = solved / cases          # element-wise division

# Aggregations (over entire array, or per axis)
cases.sum()                        # total
cases.mean()                       # average
cases.max()                        # maximum value
cases.argmax()                     # INDEX of maximum
cases.std()                        # standard deviation
np.percentile(cases, 75)           # 75th percentile

05 — Broadcasting

Broadcasting lets NumPy operate on arrays of different shapes without copies:

# Apply weights to each column of a (3, 3) matrix
weights = np.array([1.0, 1.5, 2.0])   # shape (3,)
weighted = M * weights                  # (3,3) × (3,) → broadcasts

# Rule: compare shapes right-to-left; size 1 stretches
# (3, 3) vs (3,) → OK: (3,3) vs (1,3) → each row gets same weights
Common error: Shapes (3,) and (3, 1) look similar but broadcast differently. Always check which axis you're operating along.

07 — Q&A Brain Check

Q: What is the shape of np.zeros((2, 3, 4))?
A: (2, 3, 4) — a 3-D array with 2 planes, 3 rows, 4 columns. Total 24 elements.
Q: What's the difference between a[1] and a[1:2] for a 1-D array?
A: a[1] returns a scalar. a[1:2] returns a 1-element array — different shape. Slicing always returns an array; indexing may return a scalar.
Q: Why does a * 2 not modify a in place?
A: NumPy operators return NEW arrays. To modify in place, use a *= 2 or np.multiply(a, 2, out=a).
Q: When would you use linspace vs arange?
A: Use linspace(start, stop, n) when you want exactly n evenly-spaced points between start and stop (inclusive). Use arange(start, stop, step) when you know the step size.
